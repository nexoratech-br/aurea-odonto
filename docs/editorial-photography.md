# Fotografias editoriais — visual punch pass

Imagens geradas com a ferramenta integrada `imagegen`, somente para o case conceitual. Pessoas fictícias, sem representação de profissionais reais. Nenhuma fotografia demonstra uma clínica real ou confirma equipamentos disponíveis.

Arquivos locais em `public/images/`, com versões WebP de 1200px e 720px; consulta e scanner têm versão principal de 1600px para as composições amplas. Configuração dos slots: `src/data/media.ts`. Substitua por fotografias próprias/licenciadas quando existirem; atualize alt, dimensões e recorte.
